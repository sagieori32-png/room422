# מערכת הזמנת חדרי הדרכה — מדעי הרוח (42502 · 42503 · 42504)

המערכת נמצאת בתיקייה `rooms/` ומתפרסמת בכתובת:
**https://sagieori32-png.github.io/room422/rooms/**

היא משתמשת באותו פרויקט Firebase של חדר 422 (`new-67d5d`), אבל הנתונים שלה נשמרים בנפרד (תחת `humrooms`) ויש לה רשימת משתמשים משלה.

## הגדרה חד-פעמית

### 1. כניסה עם סיסמה
אם כבר הפעלת Email/Password עבור חדר 422 — אין צורך לעשות כלום.
אחרת: Firebase Console → **Authentication → Sign-in method → Email/Password → Enable → Save**.

### 2. חוקי ה-Database
1. Firebase Console → **Realtime Database → Rules**.
2. מחליפים את **כל** התוכן בתוכן הקובץ `database.rules.json` שבתיקייה הראשית של המאגר, ולוחצים **Publish**.

הקובץ כולל גם את החוקים של חדר 422 (ללא שינוי) וגם את החוקים של המערכת החדשה. חשוב להדביק את כולו — אם מדביקים רק חלק, אחת המערכות תפסיק לעבוד.

### 3. מנהל ראשון
פותחים את האתר. כל עוד לא הוגדרו משתמשים, מופיע טופס **"הגדרה ראשונית"** — יוצרים בו את חשבון המנהל.
כדאי לעשות זאת מיד אחרי שלב 2: עד שנוצר המנהל הראשון, כל מי שנכנס לאתר יכול להירשם כמנהל.

### 4. הוספת משתמשים מורשים
בלשונית **⚙️ ניהול** → "הוספת משתמש": שם משתמש באנגלית, סיסמה ראשונית, שם, יחידה ופרטי קשר. מעבירים למשתמש את שם המשתמש והסיסמה; הוא יכול לשנות את הסיסמה דרך "החשבון שלי".

## מה המערכת עושה

| דרישה | איך זה עובד |
|---|---|
| צפייה רק למשתמשים מורשים | כניסה עם שם משתמש וסיסמה. חוקי ה-Database חוסמים קריאה למי שאינו ברשימה |
| יומן שבועי לכל החדרים | לשונית **יומן**: כל החדרים זה לצד זה, או חדר אחד בלחיצה. בנייד — יום אחד, 3 חדרים |
| סימון פנוי / תפוס / חסום | ירוק = פנוי, אדום = תפוס, כחול = ההזמנות שלי, אפור מקווקו = חסום |
| בדיקת זמינות | לשונית **בדיקת זמינות**: תאריך + שעות → מצב כל חדר וכפתור הזמנה |
| יצירת הזמנה | שם פעילות, תיאור, תאריך, שעות, מזמין, יחידה, טלפון/דוא"ל. פרטי המזמין ממולאים אוטומטית |
| חד-פעמי / שבועי / דו-שבועי | בחירה בטופס; בהזמנה חוזרת — ימים בשבוע, שעות וטווח תאריכים |
| בדיקת התנגשויות | בזמן מילוי הטופס מוצג אם החדר פנוי, אילו מועדים תפוסים ואילו חדרים אחרים פנויים. בהזמנה חוזרת אפשר לדלג על המועדים התפוסים |
| מניעת הזמנה כפולה | גם בשרת: כל חצי שעה תפוסה נרשמת, וחוקי ה-Database דוחים כתיבה למשבצת שכבר תפוסה (גם אם שני אנשים מזמינים באותה שנייה) |
| עריכה וביטול | המזמין (או מנהל): עריכת מפגש בודד או סדרה, ביטול מפגש בודד או סדרה. מפגשים שכבר התקיימו נשמרים |
| חיפוש וסינון | לשונית **חיפוש הזמנות**: חדר, טווח תאריכים, שם פעילות, שם מזמין/יחידה, "רק שלי" |
| חסימת חדרים | מנהלים: **ניהול → חסימה חדשה** (חד-פעמית או חוזרת) |

שעות פעילות: א'–ה', 08:00–20:00, ביחידות של חצי שעה. אפשר לשנות בראש הסקריפט ב-`index.html` (`DAY_START`, `DAY_END`, `WORK_DAYS`).

## הערות
- הסרת משתמש מהרשימה מבטלת את הגישה שלו מיד. חשבון הכניסה עצמו נשאר ב-Firebase Authentication, ואפשר למחוק אותו ידנית משם.
- מנהל לא יכול לאפס סיסמה של משתמש אחר מתוך האתר. אם משתמש שכח סיסמה: מסירים אותו ברשימת המשתמשים באתר, מוחקים אותו ב-Firebase Console → Authentication → Users, ויוצרים אותו מחדש באתר עם סיסמה חדשה.
- שמות המשתמשים של המערכת הזו נפרדים מאלה של חדר 422.
