⚙️ הגדרה חד-פעמית — Firebase Realtime Database (חינמי)
  1. כנס ל-console.firebase.google.com → "Add project" (שם חופשי)
  2. בתפריט שמאל: Build → Realtime Database → Create Database
  3. בחר מיקום → Start in test mode (מאפשר קריאה/כתיבה חופשית)
  4. העתק את ה-URL של ה-Database (נראה כך: https://שם-הפרויקט-rtdb.firebaseio.com)
  5. הדבק כאן:
